### 用例 #1: 查询指定SKU的库存分布

#### 基本信息
- **用例ID**: WM_MEDIUM_001
- **类别**: 数据查询（多步骤）
- **预计响应时间**: < 3秒

#### 输入
```
查询SKU-12345在各个仓库的库存分布情况
```

#### 期望输出
```
📦 SKU-12345 库存分布详情：

- **产品名称**: iPhone 15 Pro Max 256GB 深空黑
- **总库存**: 1,234 件

📊 仓库分布：
- **深圳仓**: 800件 (可用: 780件, 锁定: 20件)
  - A区: 500件 - 库位: SZ-A-001~050
  - B区: 300件 - 库位: SZ-B-001~030

  - B区: 434件 - 库位: SH-B-001~043
```

#### 验证要点
- [ ] 查询产品信息（通过产品列表API）
- [ ] 查询库存明细（通过库存详情API）
- [ ] 显示仓库分布统计
- [ ] 包含可用/锁定分类
- [ ] 包含效期状态分析
- [ ] 提供针对性建议

#### 评分标准
- **完全正确（100分）**: 所有验证点通过，数据聚合正确
- **部分正确（60分）**: 数据正确但缺少效期分析
- **错误（0分）**: 数据错误或聚合逻辑错误

#### 关联API组合（现有系统支持）
**步骤1**: 查询产品信息
- **接口**: `/api/v1/system/products?skuCode=SKU-12345`
- **Controller**: `ProductController`
- **目的**: 获取productId

**步骤2**: 查询库存明细
- **接口**: `/api/v1/inventory/detail/{productId}`
- **Controller**: `InventoryController`
- **方法**: `getProductInventoryDetail(Long productId, Long warehouseId)`
- **返回**: 按库位分布的库存明细

**步骤3**: 查询效期预警
- **接口**: `/api/v1/inventory/expiry-warning`
- **Controller**: `InventoryController`
- **过滤**: skuCode=SKU-12345

#### 数据依赖
- SKU编码: SKU-12345
- 需关联产品、库存、效期三张表数据
