# 仓库管理员 - 模糊级别测试集（基于现有API）

> **角色**: 仓库管理员 (WAREHOUSE_MANAGER)
> **难度**: 模糊 (Ambiguous)
> **用例数量**: 8个
> **特点**: 意图不明确、口语化表达、需多轮对话澄清、响应时间<15秒、基于现有API

---

## 测试用例列表

### 用例 #1: 模糊意图 - "库存情况"

#### 基本信息
- **用例ID**: WM_AMBIGUOUS_001
- **类别**: 意图澄清
- **预计响应时间**: < 3秒（首轮）

#### 输入
```
仓库的库存情况怎么样？
```

#### 期望输出（首轮）
```
您好！我理解您想了解仓库的库存情况。为了更准确地帮助您，请问您具体需要了解哪方面的库存信息？

可以选择以下选项之一：

1. 📦 **库存总体概况** - 查看总库存量、SKU种类、周转率等汇总数据
2. ⚠️ **库存预警情况** - 查看库存不足、效期预警等异常情况
3. 📊 **各仓库库存分布** - 查看深圳仓、上海仓、越南仓、泰国仓的库存分布
4. 🔍 **指定SKU库存查询** - 查询某个具体产品的库存情况
5. 📈 **库存变动趋势** - 查看近期入库/出库趋势

💡 您也可以直接说：
- "查看库存汇总"
- "深圳仓有多少库存"
- "SKU-12345的库存"
- "查看效期预警"

请告诉我您的具体需求，我会为您提供详细信息。
```

#### 验证要点
- [ ] 正确识别意图模糊
- [ ] 提供多个选项供用户选择
- [ ] 选项分类清晰合理
- [ ] 提供快捷指令示例
- [ ] 语气友好，引导明确

#### 评分标准
- **完全正确（100分）**: 所有验证点通过，引导合理
- **部分正确（70分）**: 识别正确但选项不够清晰
- **错误（0分）**: 未识别模糊或引导错误

#### 关联API（根据用户选择后调用）
**选项1** - 库存汇总:
- `/api/v1/inventory/summary`

**选项2** - 库存预警:
- `/api/v1/inventory/expiry-warning`

**选项3** - 各仓库分布:
- `/api/v1/inventory/summary-by-warehouse`

**选项4** - 指定SKU:
- `/api/v1/inventory/list?skuCode=xxx`

**选项5** - 变动趋势:
- `/api/v1/inbound/orders` + `/api/v1/outbound/orders`

### 特点
- **意图模糊**: 用户输入不明确，需要Agent澄清
- **口语化表达**: 使用日常语言，非正式术语
- **信息缺失**: 缺少必要参数或上下文
- **多轮对话**: 需要引导用户提供更多信息

### 评测重点
- **意图识别**: 正确理解模糊表达的多种可能含义
- **澄清策略**: 提供合理的选项供用户选择
- **引导能力**: 用友好的语气引导用户提供必要信息
- **示例完整**: 每个选项都有明确的示例指令

### 评分要点
- **首轮澄清**: 快速响应（<3秒），提供清晰选项
- **选项合理性**: 覆盖主要场景，分类清晰
- **用户体验**: 语气友好，引导明确，不生硬拒绝
- **后续处理**: 用户选择后能正确调用API完成任务
