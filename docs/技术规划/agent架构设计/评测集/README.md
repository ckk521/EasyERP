4. **建立质量基准** - 为后续优化提供对比依据

## 👥 角色定义

### 1. 仓库管理员 (WAREHOUSE_MANAGER)

**职责范围**:
- 全局仓库监控与管理
- 员工任务分配与调度
- 异常处理决策
- 容量规划与优化

**典型场景**:
- 查看仓库容量使用率
- 监控员工工作效率
- 处理异常事件
- 查看全局统计数据

---

## 🎯 难度级别定义

### 简单级别 (Simple)

**特征**:
- ✅ 单一意图，明确指令
- ✅ 直接数据查询，无需推理
- ✅ 单表或简单关联查询
- ✅ 响应时间 < 2秒
- ✅ 准确率要求：95%+

**典型用例**:
- "我的待办任务有哪些？"
- "SKU-12345的库存是多少？"
- "今天有多少入库单？"
- "出库单CK-001的状态是什么？"

**评测重点**:
- 数据准确性
- 响应速度
- 格式清晰度

---

### 中等级别 (Medium)

**特征**:
- ✅ 多步骤操作
- ✅ 需要数据聚合或简单计算
- ✅ 多表关联查询
- ✅ 响应时间 < 5秒
- ✅ 准确率要求：85%+

**典型用例**:
- "今天入库完成率是多少？"
- "哪些产品库存低于安全库存？"
- "深圳仓的容量使用率是多少？"
- "本周出库订单完成情况如何？"

**评测重点**:
- 计算准确性
- 数据完整性
- 分析逻辑性

---

### 复杂级别 (Complex)

**特征**:
- ✅ 多数据源关联
- ✅ 需要推理和建议
- ✅ 跨模块数据整合
- ✅ 响应时间 < 10秒
- ✅ 准确率要求：75%+

**典型用例**:
- "分析近期出库效率下降的原因"
- "给出下月补货建议"
- "哪些SKU有缺货风险？"
- "如何优化拣货路径？"

**评测重点**:
- 推理逻辑
- 建议合理性
- 方案可行性

---

### 模糊级别 (Ambiguous)

**特征**:
- ✅ 意图不明确，需澄清
- ✅ 口语化表达
- ✅ 缺乏上下文
- ✅ 需要多轮对话
- ✅ 准确率要求：65%+

**典型用例**:
- "东西不够了"
- "帮我看看仓库情况"
- "最近有点慢"
- "这个有问题"

**评测重点**:
- 意图识别
- 澄清策略
- 引导能力

## 📈 评测指标

### 核心指标

| 指标 | 计算方式 | 目标值 |
|------|---------|--------|
| **整体准确率** | 正确用例数 / 总用例数 | ≥ 80% |
| **简单级准确率** | 简单级正确数 / 简单级总数 | ≥ 95% |
| **中等级准确率** | 中等级正确数 / 中等级总数 | ≥ 85% |
| **复杂级准确率** | 复杂级正确数 / 复杂级总数 | ≥ 75% |
| **模糊级准确率** | 模糊级正确数 / 模糊级总数 | ≥ 65% |
| **平均响应时间** | 总响应时间 / 总用例数 | ≤ 5秒 |

### 分角色指标

| 角色 | 目标准确率 | 目标响应时间 |
|------|-----------|-------------|
| 仓库管理员 | ≥ 85% | ≤ 6秒 |
| 入库操作员 | ≥ 90% | ≤ 4秒 |
| 出库操作员 | ≥ 90% | ≤ 4秒 |
| 质检员 | ≥ 85% | ≤ 5秒 |
| 库存管理员 | ≥ 85% | ≤ 5秒 |
