# 客户退货功能需求

> 模块说明: 处理客户收到货后的退货流程
> 优先级: P1
> 关联模块: 出库管理（关联原出库单）、入库管理（生成退货入库单）

---

## 一、业务背景

### 1.1 业务场景

客户在收到货物后，因以下原因申请退货：
- 商品质量问题（破损、功能缺陷）
- 发错商品/数量不符
- 客户主观原因（不满意、拍错等）
- 7天无理由退货

### 1.2 流程定位

```
正向流程：
供应商 → 仓库 → 客户

退货流程（逆向）：
客户 → 仓库（退货入库）→ 质检 → 上架/处理
```

## 三、功能需求

### Story 1: 退货单列表

**作为** 仓库管理员
**我希望** 查看所有退货单列表
**以便** 管理和追踪退货处理进度

**验收标准:**
- [ ] 显示退货单列表，包含：退货单号、原出库单号、客户信息、退货数量、状态、创建时间
- [ ] 支持按状态筛选：全部/待收货/已收货/已完成/已取消
- [ ] 支持按退货单号、原出库单号搜索
- [ ] 支持按时间范围筛选
- [ ] 点击退货单可查看详情

**列表字段:**

| 字段 | 说明 |
|-----|------|
| 退货单号 | 系统生成，格式：RT + 年月日 + 序号 |
| 原出库单号 | 关联的原出库单 |
| 客户名称 | 原出库单的客户 |
| 退货商品数 | 退货商品SKU数量 |
| 退货数量 | 退货总数量 |
| 状态 | 待收货/已收货/已完成/已取消 |
| 创建时间 | 退货单创建时间 |
| 操作 | 查看/收货/取消 |

### Story 2: 创建退货单

**作为** 仓库管理员
**我希望** 手动创建退货单
**以便** 记录客户的退货申请

**验收标准:**
- [ ] 选择原出库单（通过出库单号搜索）
- [ ] 自动带出原出库单的客户信息
- [ ] 显示原出库单的商品明细
- [ ] 选择退货商品并录入退货数量
- [ ] 录入退货原因
- [ ] 退货数量不能超过原出库数量
- [ ] 提交后状态为"待收货"

**创建表单字段:**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| 原出库单号 | 搜索选择 | 是 | 搜索并选择原出库单 |
| 客户名称 | 自动带出 | - | 根据原出库单自动显示 |
| 退货原因 | 下拉+文本 | 是 | 预设原因+详细说明 |
| 退货商品 | 表格 | 是 | 从原出库单商品中选择 |
| - 商品SKU | 自动带出 | - | 原出库单商品 |
| - 商品名称 | 自动带出 | - | 原出库单商品 |
| - 原出库数量 | 自动带出 | - | 原出库单数量 |
| - 退货数量 | 输入 | 是 | 不能超过原出库数量 |
| 备注 | 文本 | 否 | 补充说明 |

**退货原因选项:**
1. 商品质量问题（破损/功能缺陷）
2. 发错商品
3. 数量不符
4. 客户不满意
5. 7天无理由退货
6. 其他

### Story 3: 退货收货

**作为** 仓库管理员
**我希望** 确认客户退回的商品已收到
**以便** 触发生成入库单

**验收标准:**
- [ ] 在退货单详情页点击"确认收货"
- [ ] 显示退货商品列表，录入实际收货数量
- [ ] 实收数量可以小于预计数量（客户可能少退）
- [ ] 可以录入收货备注（如外包装破损情况）
- [ ] 确认收货后：
  - 状态变为"已收货"
  - 自动生成入库单（类型：客户退货）
  - 入库单关联退货单号
- [ ] 可查看生成的入库单号

**收货界面字段:**

| 字段 | 说明 |
|-----|------|
| 商品SKU | 退货商品 |
| 商品名称 | 商品名称 |
| 预计退货数量 | 退货单中的数量 |
| 实收数量 | 实际收到的数量（手动输入） |
| 收货备注 | 可选，记录特殊情况 |

## 四、数据关联

### 4.1 与出库单的关联

```
退货单 (return_order)
    │
    ├── original_outbound_id → 出库单ID
    ├── original_outbound_no → 出库单号
    │
    └── 约束：退货数量 ≤ 原出库数量
```

### 4.2 与入库单的关联

```
退货单 (return_order)
    │
    │ 收货确认后
    ▼
入库单 (inbound_order)
    │
    ├── order_type = 4 (客户退货)
    ├── source_return_id → 退货单ID
    ├── source_return_no → 退货单号
    │
    └── 入库流程：收货 → 验收 → 上架
```

## 六、数据库设计

### 6.1 退货单主表

```sql
CREATE TABLE wms_return_order (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    return_no VARCHAR(32) NOT NULL COMMENT '退货单号 RT202606060001',

    -- 关联原出库单
    original_outbound_id BIGINT COMMENT '原出库单ID',
    original_outbound_no VARCHAR(32) COMMENT '原出库单号',

    -- 客户信息（从出库单带出）
    customer_id BIGINT COMMENT '客户ID',
    customer_name VARCHAR(64) COMMENT '客户名称',

    -- 退货原因
    return_reason TINYINT COMMENT '退货原因: 1质量问题 2发错货 3数量不符 4不满意 5无理由 6其他',
    return_reason_text VARCHAR(200) COMMENT '退货原因详细说明',

    -- 状态
    status TINYINT DEFAULT 0 COMMENT '状态: 0待收货 1已收货 2已完成 9已取消',

    -- 数量汇总
    total_expected_qty INT DEFAULT 0 COMMENT '预计退货数量',
    total_received_qty INT DEFAULT 0 COMMENT '实际收货数量',

    -- 关联入库单
    inbound_order_id BIGINT COMMENT '生成的入库单ID',
    inbound_order_no VARCHAR(32) COMMENT '生成的入库单号',

    -- 仓库
    warehouse_id BIGINT COMMENT '仓库ID',
    warehouse_code VARCHAR(32) COMMENT '仓库编码',

    -- 取消信息
    cancel_reason VARCHAR(200) COMMENT '取消原因',

    -- 审计字段
    create_user_id BIGINT COMMENT '创建人ID',
    create_user_name VARCHAR(32) COMMENT '创建人姓名',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    complete_time DATETIME COMMENT '完成时间',

    UNIQUE KEY uk_return_no (return_no),
    KEY idx_status (status),
    KEY idx_outbound (original_outbound_id)
) COMMENT '退货单主表';
```

### 6.2 退货单明细表

```sql
CREATE TABLE wms_return_order_item (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    return_order_id BIGINT NOT NULL COMMENT '退货单ID',
    return_order_no VARCHAR(32) NOT NULL COMMENT '退货单号',

    -- 商品信息
    product_id BIGINT COMMENT '商品ID',
    sku_code VARCHAR(32) COMMENT 'SKU编码',
    product_name VARCHAR(128) COMMENT '商品名称',
    barcode VARCHAR(64) COMMENT '条码',

    -- 数量
    original_qty INT DEFAULT 0 COMMENT '原出库数量',
    expected_qty INT DEFAULT 0 COMMENT '预计退货数量',
    received_qty INT DEFAULT 0 COMMENT '实际收货数量',

    -- 备注
    remark VARCHAR(200) COMMENT '备注',

    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',

    KEY idx_return_order (return_order_id)
) COMMENT '退货单明细表';
```
