# 异常管理模块 - 产品需求文档

> 版本: 1.0 | 创建日期: 2026-05-07 | 作者: Claude

---

## 一、模块概述

### 1.1 模块定位

异常管理模块用于处理仓储作业过程中发现的异常商品，提供从异常登记、隔离入库到异常处理的完整流程管理。

### 1.2 业务场景

异常管理模块的数据来源主要有两个入口：

#### 1.2.1 收货作业入口
- **触发时机**：收货员在收货作业页面，发现商品存在异常
- **操作方式**：点击"异常登记"按钮，系统自动带入入库单信息
- **数据关联**：自动关联当前入库单、采购订单、供应商信息

#### 1.2.2 验收作业入口
- **触发时机**：质检员在验收作业页面，发现商品质量不合格
- **操作方式**：点击"异常登记"按钮，系统自动带入入库单信息
- **数据关联**：自动关联当前入库单、采购订单、供应商信息

#### 1.2.3 典型异常场景
- **收货异常**：收货时发现商品破损、短缺、质量不合格、错货等
- **质检异常**：验收时发现商品不符合质量标准
- **存储异常**：存储过程中发现的商品变质、损坏等

### 1.3 核心价值

1. **完整追溯**：记录异常商品从发现到处理的全过程
2. **隔离管理**：将异常商品隔离存放，避免与正常库存混淆
3. **多种处理**：支持退货、换货、报废、降价销售等多种处理方式
4. **数据关联**：绑定入库单、采购订单、供应商信息，便于责任追溯

### 3.3 异常类型枚举

| 值 | 名称 | 说明 |
|----|------|------|
| 1 | 破损 | 商品包装或本身破损 |
| 2 | 短缺 | 实际收货数量少于预期 |
| 3 | 质量不合格 | 商品质量不符合标准 |
| 4 | 错货 | 发货错误，商品与订单不符 |
| 5 | 其他 | 其他异常情况 |

### 3.4 处理方式枚举

| 值 | 名称 | 说明 |
|----|------|------|
| 1 | 退货 | 退回供应商 |
| 2 | 换货 | 供应商换货 |
| 3 | 报废 | 商品报废处理 |
| 4 | 降价销售 | 降价后正常销售 |

### 3.5 异常处理单状态枚举

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | 待处理 | 异常已登记，等待处理 |
| 1 | 处理中 | 正在进行异常处理（已隔离入库） |
| 2 | 已完成 | 异常处理完成 |
| 3 | 已取消 | 异常处理取消 |

### 3.6 已取消状态的业务逻辑

当异常处理单被取消时，系统执行以下操作：

1. **数量恢复**：异常商品数量恢复到原入库单的待收货/待验收数量
2. **状态回滚**：如果入库单因此恢复到可操作状态，自动更新入库单状态
3. **库存处理**：
   - 如果已执行隔离入库：隔离库存自动扣减，释放库位
   - 如果未执行隔离入库：无库存变动
4. **操作记录**：记录取消原因、取消人、取消时间
5. **后续操作**：操作人员可在收货/验收作业中继续处理这些商品

**取消条件：**
- 待处理状态：可直接取消
- 处理中状态：需先撤销隔离入库，再取消
- 已完成状态：不可取消

## 四、功能需求

### 4.1 异常登记

#### 4.1.1 收货异常登记

**功能描述：** 在收货环节发现异常商品时，进行异常登记。

**前置条件：**
- 已创建入库单
- 已完成收货登记

**操作流程：**
1. 用户在收货登记页面，点击"异常登记"按钮
2. 系统弹出异常登记对话框
3. 用户选择异常商品、填写异常数量、选择异常类型、填写异常原因
4. 用户选择隔离库区
5. 用户确认提交
6. 系统创建异常处理单，状态为"待处理"

**输入项：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 入库单号 | 文本 | 是 | 自动带出，不可编辑 |
| 供应商 | 文本 | 是 | 自动带出，不可编辑 |
| 商品列表 | 表格 | 是 | 从收货商品中选择 |
| 异常类型 | 下拉 | 是 | 破损/短缺/质量不合格/错货/其他 |
| 异常数量 | 数字 | 是 | 必须大于0 |
| 异常原因 | 文本 | 否 | 最多500字 |
| 隔离库区 | 下拉 | 是 | 选择隔离类型的库区 |
| 备注 | 文本 | 否 | 最多500字 |

**业务规则：**
1. 异常数量不能超过该商品的收货数量
2. 隔离库区必须是"残次品区"类型的库区
3. 同一入库单可以创建多个异常处理单
4. 异常登记后，该商品的正常收货数量自动扣减

#### 4.1.2 质检异常登记

**功能描述：** 在质检环节发现异常商品时，进行异常登记。

**前置条件：**
- 已完成收货登记
- 商品处于待质检状态

**操作流程：** 与收货异常登记类似

---

### 4.2 隔离入库

**功能描述：** 将异常商品入到隔离库区。

**前置条件：**
- 异常处理单状态为"待处理"
- 已选择隔离库区

**操作流程：**
1. 用户在异常处理单详情页，点击"隔离入库"按钮
2. 系统显示隔离库区下的可用库位
3. 用户选择或扫描库位
4. 用户确认入库
5. 系统更新异常处理单状态为"处理中"
6. 系统增加隔离库区的库存

**业务规则：**
1. 隔离入库后，库存状态标记为"隔离"
2. 隔离库存不参与正常出库
3. 需要记录库位信息

---

### 4.3 异常处理

#### 4.3.1 退货处理

**功能描述：** 将异常商品退回供应商。

**前置条件：**
- 异常处理单状态为"处理中"
- 商品已完成隔离入库

**操作流程：**
1. 用户选择"退货"处理方式
2. 系统生成退货单（关联异常处理单）
3. 用户填写退货物流信息
4. 用户确认退货
5. 系统扣减隔离库存
6. 系统更新异常处理单状态为"已完成"

**输出：**
- 生成退货单据
- 扣减隔离库存
- 更新异常处理单状态

#### 4.3.2 换货处理

**功能描述：** 等待供应商换货，换货后重新入库。

**操作流程：**
1. 用户选择"换货"处理方式
2. 系统记录换货申请
3. 供应商换货到货后，用户进行换货入库
4. 系统扣减隔离库存，增加正常库存
5. 系统更新异常处理单状态为"已完成"

#### 4.3.3 报废处理

**功能描述：** 商品无法修复或销售，进行报废处理。

**操作流程：**
1. 用户选择"报废"处理方式
2. 用户填写报废原因
3. 用户确认报废
4. 系统扣减隔离库存
5. 系统更新异常处理单状态为"已完成"

#### 4.3.4 降价销售

**功能描述：** 商品存在轻微瑕疵，降价后正常销售。

**操作流程：**
1. 用户选择"降价销售"处理方式
2. 用户填写降价比例或金额
3. 用户确认处理
4. 系统将库存状态从"隔离"改为"正常"
5. 系统更新异常处理单状态为"已完成"

### 4.4 异常查询

#### 4.4.1 异常处理单列表

**功能描述：** 查询异常处理单列表。

**查询条件：**
- 异常处理单号
- 入库单号
- 供应商
- 异常类型
- 状态
- 创建时间范围

**列表字段：**
- 异常处理单号
- 入库单号
- 供应商
- 异常类型
- 异常数量
- 状态
- 处理方式
- 创建时间
- 操作（查看详情）

#### 4.4.2 异常处理单详情

**功能描述：** 查看异常处理单详情。

**详情内容：**
- 基本信息：单号、状态、创建时间等
- 关联信息：入库单、采购订单、供应商
- 异常商品列表：商品、数量、异常类型、异常原因
- 处理记录：处理方式、处理结果、处理人、处理时间
- 操作日志

---

### 4.5 异常统计报表

**功能描述：** 统计异常数据，支持供应商评估。

**统计维度：**
- 按供应商统计异常数量、异常率
- 按异常类型统计
- 按时间段统计

### 5.1 API列表

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 创建异常处理单 | POST | /api/v1/exception-orders | 从收货页面创建异常处理单 |

## 六、权限设计

| 权限编码 | 权限名称 | 说明 |
|----------|----------|------|
| exception:register | 异常登记 | 收货、质检时登记异常 |

## 七、非功能需求

### 7.1 性能要求
- 异常处理单列表查询响应时间 < 2秒
- 异常登记操作响应时间 < 1秒

### 7.2 数据要求
- 异常处理单数据保留时间：永久
- 支持导出Excel格式

### 7.3 安全要求
- 所有操作需要登录认证
- 敏感操作（报废、降价销售）需要权限验证
