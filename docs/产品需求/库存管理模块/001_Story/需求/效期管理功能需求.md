# 效期管理功能 - 详细需求文档

> Story: 4.17 效期预警监控, 4.18 FEFO出库策略
> 优先级: P0 (Story 4.17), P1 (Story 4.18)
> 版本: 1.0
> 创建日期: 2026-05-27

---

## 一、功能概述

效期管理是仓储管理的核心功能之一：
- **效期预警监控**：自动计算商品效期状态，临期/过期商品提醒
- **FEFO出库策略**：先过期先出（First Expired, First Out），减少过期损耗

### 2.3 效期状态定义

| 状态 | 图标 | 条件 | 颜色 | 处理建议 |
|-----|------|------|------|---------|
| 正常 | - | 距过期 > 预警天数 | 🟢 绿色 | 正常销售 |
| 效期预警 | ⚠ | 距过期 ≤ 预警天数 且 > 预警天数/2 | 🟡 黄色 | 关注，建议优先出库 |
| 临期 | 🔴 | 距过期 ≤ 预警天数/2 且 > 0 | 🔴 红色 | 紧急处理，降价或报废 |
| 已过期 | ⚫ | 已过过期日期 | ⚫ 灰色 | 禁止出库，报废处理 |

## 三、Story 4.18 FEFO出库策略

### 3.1 功能说明

FEFO（First Expired, First Out）先过期先出策略：
- 出库时自动分配最早过期的批次
- 减少过期损耗
- 可按商品设置开启/关闭

```
   │ │B002      │A-R02│  50  │2026-07-15│⚠预警│ ← 次优先            │

   │ └──────────┴────┴──────┴──────────┴──────┘                     │

   ┌────────────────────────────────────────────────────────────────┐
   │ 分配明细：                                                      │
   │ 批次B001（临期）：分配 30件                                    │
   │ 批次B002（预警）：分配 20件                                    │

   │                                                                 │
   │ 分配原因：                                                      │

   │ - B003批次正常，暂不分配                                       │

4. 生成拣货任务
```
