# 库存查询功能 - 详细需求文档

> Story: 4.1 实时库存查询, 4.2 库存明细查询, 4.3 批次库存查询
> 优先级: P0 (MVP必需)
> 版本: 1.0
> 创建日期: 2026-05-27

---

## 一、功能概述

库存查询是库存管理模块的核心入口，提供三种查询视角：
- **实时库存查询**：全局视角，查看所有库存汇总
- **库存明细查询**：单品视角，查看单个商品的库位分布
- **批次库存查询**：批次视角，按批次号查询库存（效期管理核心）

### 2.3 查询条件详解

| 字段 | 类型 | 说明 | 交互示例 |
|-----|------|------|---------|
| SKU/名称/条码 | 文本输入 | 支持模糊搜索，输入后按回车或点击查询 | 输入"海飞丝"查询所有海飞丝商品 |
| 仓库 | 下拉单选 | 显示用户有权限的仓库列表 | 选择"深圳总仓" |
| 库区 | 下拉单选 | 根据仓库联动显示库区 | 选择仓库后显示"仓储A部"等 |
| 库位 | 文本输入 | 支持库位编码模糊搜索 | 输入"A01"查询A01开头的库位 |
| 批次号 | 文本输入 | 精确或模糊匹配批次号 | 输入"IN202605"查询5月入库批次 |
| 效期状态 | 下拉单选 | 正常/预警/临期/已过期 | 选择"临期"查看所有临期商品 |
| 分类 | 下拉单选 | 商品分类树形选择 | 选择"洗护用品"分类 |

### 4.3 效期状态定义

| 状态 | 图标 | 条件 | 颜色 | 说明 |
|-----|------|------|------|------|
| 正常 | - | 距过期 > 预警天数(30天) | 绿色 | 库存可正常使用 |
| 效期预警 | ⚠ | 距过期 ≤ 30天 且 > 15天 | 黄色 | 需要关注，建议优先出库 |
| 临期 | 🔴 | 距过期 ≤ 15天 且 > 0天 | 红色 | 紧急处理，降价出库或报废 |
| 已过期 | ⚫ | 已过过期日期 | 灰色 | 禁止出库，需报废处理 |

## 十四、性能优化

### 14.1 大数据量处理

| 场景 | 处理方式 |
|-----|---------|
| 数据量 > 10万条 | 强制要求输入筛选条件，不允许全量查询 |
| 列表渲染 | 使用虚拟滚动技术，只渲染可见区域 |
| 分页 | 默认20条/页，支持50/100/200条切换 |
| 导出 | 超过1万条时异步导出，完成后通知下载 |

### 14.2 缓存策略

| 数据 | 缓存时间 | 刷新条件 |
|-----|---------|---------|
| 库存列表 | 30秒 | 手动刷新、执行操作后 |
| 统计卡片 | 30秒 | 手动刷新、执行操作后 |
| 下拉选项 | 5分钟 | 无 |

### 14.3 查询优化

```
系统响应：
- 输入查询条件后，防抖500ms再发起请求
- 支持查询条件保存，下次进入自动加载
- 查询结果缓存，相同条件不重复请求
```
