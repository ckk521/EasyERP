# 库存冻结与调整功能 - 详细需求文档

> Story: 4.14 库存冻结, 4.15 库存解冻, 4.16 库存调整单
> 优先级: P1 (MVP需要)
> 版本: 1.0
> 创建日期: 2026-05-27

---

## 一、功能概述

库存冻结与调整是库存管理的特殊操作：
- **库存冻结**：暂停特定库存的分配和出库
- **库存解冻**：恢复冻结库存的正常使用
- **库存调整**：手动调整库存数量（盘盈盘亏、损耗等）

### 2.4 冻结原因选项

| 原因 | 说明 | 自动解冻 |
|-----|------|---------|
| 盘点 | 盘点期间临时冻结 | 盘点完成后自动解冻 |
| 质检 | 质量问题待检验 | 质检完成后处理 |
| 问题商品 | 发现问题的商品 | 手动处理 |
| 客户锁定 | 客户预留库存 | 订单取消后解冻 |
| 其他 | 其他原因 | 手动解冻 |

### 2.5 交互场景

#### 场景1：创建库存冻结
```
用户操作：
1. 点击[新增冻结]按钮
2. 选择仓库：深圳总仓
3. 选择冻结原因：盘点
4. 点击[添加商品]选择要冻结的商品
5. 输入冻结数量
6. 填写冻结说明
7. 点击[保存]

- 验证冻结数量不超过可用数量
- 扣减可用数量，增加锁定数量
```

### 4.3 调整类型说明

| 类型 | 说明 | 数量方向 | 审批规则 |
|-----|------|---------|---------|
| 盘盈 | 盘点时实际数量多于系统数量 | +（增加） | 金额>¥100需审批 |
| 盘亏 | 盘点时实际数量少于系统数量 | -（减少） | 金额>¥100需审批 |
| 损耗 | 商品损耗、破损等 | -（减少） | 金额>¥200需审批 |
| 赠送 | 赠品入库 | +（增加） | 金额>¥500需审批 |
| 其他 | 其他原因调整 | +/- | 金额>¥100需审批 |

## 六、API接口设计

### 6.1 创建库存冻结

```
POST /api/v1/inventory/freeze

请求参数:
{
  "warehouseId": 9,
  "freezeReason": 1,
  "freezeRemark": "盘点期间临时冻结",
  "expectedUnfreezeDate": "2026-05-28",
  "items": [
    {
      "inventoryId": 11,
      "freezeQty": 10
    }
  ]
}

响应示例:
{
  "success": true,
  "message": "库存冻结成功",
  "data": {
    "freezeNo": "FR20260527001"
  }
}
```

### 6.2 库存解冻

```
POST /api/v1/inventory/unfreeze

请求参数:
{
  "freezeId": 1,
  "unfreezeQty": 10,
  "unfreezeRemark": "盘点已完成"
}

响应示例:
{
  "success": true,
  "message": "库存解冻成功"
}
```

### 6.3 创建库存调整单

```
POST /api/v1/inventory/adjust/create

请求参数:
{
  "warehouseId": 9,
  "adjustType": 1,
  "adjustReason": "盘点差异",

    }
  ],

  "data": {
    "id": 1,

  }
}
```
