# 库存调拨功能 - 详细需求文档

> Story: 4.8 调拨单创建, 4.9 调拨出库, 4.10 调拨入库, 4.11 调拨查询
> 优先级: P1 (MVP需要)
> 版本: 1.0
> 创建日期: 2026-05-27

---

## 一、功能概述

库存调拨实现库存在不同位置间的转移：
- **库位间调拨**：同仓库内不同库位的转移
- **仓库间调拨**：跨仓库的库存转移

调拨流程：创建调拨单 → 调拨出库 → 调拨入库 → 完成

### 2.4 调拨原因选项

| 原因 | 说明 |
|-----|------|
| 补货 | 向库存不足的仓库/库位补货 |
| 整理 | 库位整理、优化存储 |
| 调剂 | 仓库间库存调剂 |
| 退货 | 退回供应商（需出库） |
| 其他 | 其他原因 |
