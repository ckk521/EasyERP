# 库存预警功能 - 详细需求文档

> Story: 4.12 库存预警设置, 4.13 库存预警通知
> 优先级: P1 (MVP需要)
> 版本: 1.0
> 创建日期: 2026-05-27

---

## 一、功能概述

库存预警系统帮助企业及时发现库存异常，包括：
- **库存不足预警**：库存低于安全库存时提醒补货
- **库存超储预警**：库存超过最大库存时提醒处理
- **效期预警**：商品临期/过期时提醒处理
- **呆滞预警**：长期无动销商品提醒

### 2.4 预警类型说明

| 类型 | 触发条件 | 预警级别 | 处理建议 |
|-----|---------|---------|---------|
| 库存不足 | 可用数量 ≤ 安全库存 | 紧急/重要 | 立即补货 |
| 库存超储 | 可用数量 ≥ 最大库存 | 重要/一般 | 促销清货 |
| 效期预警 | 距过期 ≤ 预警天数 | 重要 | 优先出库 |
| 临期紧急 | 距过期 ≤ 预警天数/2 | 紧急 | 降价处理/报废 |
| 已过期 | 已过过期日期 | 紧急 | 报废处理 |
| 呆滞库存 | 无出库 > 呆滞天数 | 一般 | 清理/退货 |

### 2.5 交互场景

#### 场景1：新增库存不足预警规则
```
用户操作：
1. 点击[新增规则]按钮
2. 选择预警类型：库存不足
3. 设置适用范围：按指定商品 - SKU-009
4. 设置安全库存阈值：10件
5. 选择预警级别：紧急
6. 设置通知人和通知方式
7. 点击[保存]

系统响应：
- 创建预警规则
- 每日定时检查该商品库存
- 当库存≤10件时触发预警

实际案例：

## 五、API接口设计

### 5.1 创建预警规则

```
POST /api/v1/alert/rule/create

请求参数:
{
  "ruleName": "海飞丝库存不足预警",
  "alertType": 1,
  "alertLevel": 1,
  "scopeType": 3,
  "scopeData": ["SKU-009"],
  "thresholdValue": 10,
  "thresholdUnit": "件",
  "notifyMethod": "message,email",
  "notifyUsers": [1, 2],
  "status": 1
}

响应示例:
{
  "success": true,
  "message": "预警规则创建成功",
  "data": {
    "id": 1
  }
}
```

```

请求参数:

### 5.3 处理预警

```
POST /api/v1/alert/handle

请求参数:
{
  "alertId": 1,
  "handleType": 1,    // 1-创建采购单,2-标记已处理,3-忽略
  "handleRemark": "已创建采购订单",
  "ignoreDays": 0     // 忽略时设置免打扰天数
}

响应示例:
{
  "success": true,
  "message": "预警处理成功",
  "data": {
    "purchaseOrderId": 123  // 如果创建了采购单
  }
}
```
