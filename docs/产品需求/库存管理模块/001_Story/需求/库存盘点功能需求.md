# 库存盘点功能 - 详细需求文档

> Story: 4.4 盘点单创建, 4.5 盘点作业, 4.6 盘点差异处理, 4.7 盘点历史查询
> 优先级: P0 (MVP必需 - Story 4.4-4.6), P1 (Story 4.7)
> 版本: 1.1
> 创建日期: 2026-05-27
> 更新日期: 2026-05-28

---

## 一、功能概述

库存盘点是确保账实相符的核心功能，支持：
- **盘点单创建**：支持全盘、抽盘、循环盘点
- **盘点作业**：执行盘点、记录实际数量
- **差异处理**：分析差异原因、生成调整单
- **历史查询**：盘点记录追溯、准确率分析

### 2.4 盘点类型说明

| 类型 | 说明 | 适用场景 | 示例 |
|-----|------|---------|------|
| 全盘 | 盘点仓库内所有库存 | 年度盘点、季度盘点 | 深圳总仓全部156个SKU |
| 抽盘 | 盘点指定范围内的库存 | 月度抽查、重点商品盘点 | 只盘点仓储A部的商品 |
| 循环盘点 | 按计划定期盘点部分库存 | 高价值商品每周盘点 | A类商品每周盘点 |

### 2.5 盘点模式说明

| 模式 | 说明 | 优缺点 |
|-----|------|--------|
| 明盘 | 盘点时显示系统数量，自动计算差异 | 优点：效率高，差异明显；缺点：可能影响盘点准确性 |
| 盲盘 | 盘点时不显示系统数量，只录入实际数量 | 优点：更准确；缺点：效率较低，无法实时发现差异 |

**盲盘差异显示规则（用户确认）：**
- 单条录入后立即显示差异，便于及时发现异常

### 2.6 业务规则说明

**进度统计规则（用户确认）：**
- 按库存记录数统计进度（一个SKU多库位算多条记录）

**批次盘点规则（用户确认）：**
- 同一库位同一SKU有多个批次时，按批次分别盘点

**复盘功能（用户确认）：**
- 盘点人手动触发复盘功能
- 系统记录初盘和复盘结果，以复盘结果为准

**取消盘点处理（用户确认）：**
- 差异报告只统计已盘点的部分
- 取消后的库存状态恢复（不生效差异调整）

### 4.3 差异原因选项

| 原因 | 说明 | 处理方式 |
|-----|------|---------|
| 盘盈 | 实际数量多于系统数量 | 生成盘盈调整单 |
| 盘亏 | 实际数量少于系统数量 | 生成盘亏调整单 |
| 错放 | 商品被放在错误的库位 | 移库处理 |
| 漏扫 | 之前出入库时漏扫描 | 补录出入库记录 |
| 损耗 | 商品破损、丢失等 | 生成损耗调整单 |
| 其他 | 其他原因 | 手动处理 |

### 4.4 审批流程

```
差异金额 ≤ ¥100    →  自动通过，直接调整库存
¥100 < 差异金额 ≤ ¥500  →  仓库主管审批
差异金额 > ¥500    →  仓库主管 + 财务审批
```
